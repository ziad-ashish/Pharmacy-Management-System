# شفاء OS

نظام سطح مكتب لإدارة الصيدليات يعمل محليًا باستخدام PyWebView وFlask وSQLite.

## التشغيل

شغّل `run.bat`. سيتحقق الملف من Python والمتطلبات ثم يفتح التطبيق.

الحساب الإداري الافتراضي عند إنشاء قاعدة بيانات جديدة:

- اسم المستخدم: `admin`
- كلمة المرور: `admin123`

يجب تغيير كلمة المرور الافتراضية بعد أول دخول.

## هيكل المشروع

- `main.py`: تشغيل نافذة سطح المكتب وخادم Flask المحلي.
- `api.py`: قاعدة البيانات ومنطق العمل.
- `routes.py`: واجهة REST المحلية.
- `src/js/data.js`: طبقة الاتصال الموحدة بين الواجهة والخادم.
- `src/js/pages/`: وحدات شاشات النظام.
- `src/css/professional.css`: نظام التصميم والهوية النهائية.

## الوحدات

لوحة العمليات، المخزون والأدوية، نقطة البيع، الفواتير، المرضى، الموردون، التقارير والإعدادات.
